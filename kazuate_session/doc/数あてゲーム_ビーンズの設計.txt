ビーンズの設計方針

実は、スッキリ本では、ビーンズを「データの入れ物」としており、
そのデータを設定したり、更新したりするのは「ロジック・クラス」の
責務だとしています。

ですので、その考え方だと、たとえば次のようになると思います。

+-------------------------+
|  Com                    |
+-------------------------+
| -number :int            |
| -msg    :String         |
+-------------------------+
| +Com()                  |
| +getNumber()    :int    |
| +setNumber(int) :void   |
| +getMsg()       :String |
| +setMsg(String) :void   |
+-------------------------+

+------------------+
| SetNumberLogic   | ランダムに数を設定するロジック
+------------------+
|                  |
+------------------+
| +execute() :void |
+------------------+

+---------------------------+
| JudgeLogic                | userとcomのnumberを比べて 
+---------------------------+ 判定の文字列をcomにセット
|                           | するロジッック
+---------------------------+
| +execute(int,Com) :String |
+---------------------------+
